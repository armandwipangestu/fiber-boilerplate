# Phase 20 — API Documentation (Swagger / OpenAPI)

> Interactive API docs generated by `swaggo/swag` and served by
> `gofiber/contrib/swagger` in development mode.

## Deliverables

### 20.1 Swag CLI
```bash
go install github.com/swaggo/swag/cmd/swag@latest
```

### 20.2 OpenAPI annotations
- General metadata (`@title`, `@version`, `@description`, `@host`,
  `@BasePath /api/v1`) and the `BearerAuth` API-key security scheme in
  `cmd/server/main.go`.
- Per-handler `@Summary` / `@Tags` / `@Param` / `@Success` / `@Failure` /
  `@Router` annotations across:
  - Auth: `register`, `login`, `refresh`, `logout`
  - Users: `create`, `list`, `get`, `update`, `delete`, avatar upload/delete
  - RBAC: roles and permissions management + user role visibility
  - Health: `live` / `ready` / `health`
- Protected endpoints carry `@Security BearerAuth`.

### 20.3 Generate docs
```bash
swag init -g cmd/server/main.go -o docs/swagger
```
Emits `docs.go`, `swagger.json`, `swagger.yaml`.

### 20.4 Serve Swagger UI (dev only)
- Mounted when `SWAGGER_ENABLED=true` **and** `APP_ENV=development`:
  - UI: `GET /swagger` (swagger-ui)
  - Spec: `GET /docs/swagger/swagger.json`

## Verify
- `APP_ENV=development SWAGGER_ENABLED=true` → `/swagger` returns the UI
  (200 HTML) and the generated spec lists every annotated path with the
  BearerAuth security scheme.
